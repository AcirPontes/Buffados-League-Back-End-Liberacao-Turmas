# Referências institucionais consultadas

Consulta realizada em 3 de novembro de 2026. As referências orientam a modelagem e a navegação do protótipo; não significam integração automática com sistemas institucionais.

## Departamentos de área — IFMT Campus Cuiabá

https://cba.ifmt.edu.br/ensino/departamentos-de-area/

A página institucional apresenta os cinco departamentos considerados no sistema: DABC, DCOM, DEEA, DGH e DINFRA. A associação dos cursos técnicos a DCOM, DINFRA, DGH e DEEA foi modelada conforme a orientação fornecida para o trabalho. O DABC foi tratado como departamento transversal para disciplinas da Base Comum.

## Horário escolar — EduPage

https://ifmtcba.edupage.org/timetable/

O quadro de horários permite consultar informações organizadas por turmas, professores e salas/laboratórios. O projeto oferece um link para consulta manual. Não implementa raspagem, importação ou sincronização, pois não foi identificada uma API institucional autorizada para esse fim.

## SUAP — autenticação institucional

https://suap.ifmt.edu.br/accounts/login/

O SUAP é apresentado apenas como referência visual/conceitual para o uso de matrícula como identificador. O protótipo não recolhe a senha SUAP nem simula autenticação institucional. Para validar vínculo acadêmico e autenticar de forma oficial, será necessária autorização do IFMT e integração com o provedor de identidade institucional.

## Observação sobre o escopo

Os departamentos e a grade horária podem mudar. Antes de uma implantação real, a coordenação deve confirmar os responsáveis, a abrangência de cada departamento, os cursos/turmas ativos e os procedimentos formais para liberação de estudantes.
